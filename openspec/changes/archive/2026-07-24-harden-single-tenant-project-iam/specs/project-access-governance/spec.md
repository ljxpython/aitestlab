## ADDED Requirements

### Requirement: 项目内容必须通过显式成员关系隔离
每次项目内容操作 MUST 具备活动的人类用户成员关系，或具备活动的服务账号项目 grant 及允许该操作的项目角色；系统还必须验证目标资源确实属于已授权项目。

#### Scenario: 用户将项目标识替换为其他项目
- **当** 仅有项目 A 权限的用户请求属于项目 B 的资源，并在客户端上下文中提交项目 A 或项目 B
- **那么** 系统拒绝请求，且不得返回项目 B 的数据

#### Scenario: 平台超级管理员不是项目成员
- **当** 未加入项目的超级管理员请求项目知识库、测试用例、助手或 runtime 内容
- **那么** 系统拒绝内容访问

### Requirement: 项目创建必须显式治理
系统 MUST 在创建项目之前校验平台项目创建权限，并将项目创建在服务端默认租户中，同时至少建立一个显式项目管理员。

#### Scenario: 超级管理员创建项目
- **当** 超级管理员提交有效项目数据
- **那么** 系统在默认租户中创建项目，并将创建者显式加入为 `project_admin`

#### Scenario: 普通认证用户创建项目
- **当** 不具备平台项目创建权限的用户提交创建请求
- **那么** 系统拒绝请求，且不创建项目或成员关系

### Requirement: 平台角色治理项目元数据但不授予内容访问
系统 MUST 允许具备相应平台权限的角色查看全局项目清单；只有超级管理员可以创建、归档、恢复项目或恢复项目管理员，但这些能力不得自动授予项目内容访问权。

#### Scenario: 平台只读者查看项目清单
- **当** 平台只读者请求全局项目清单
- **那么** 系统返回允许查看的项目元数据，但不授予项目内容访问权

#### Scenario: 平台操作员尝试修改项目生命周期
- **当** 平台操作员尝试归档、恢复项目或恢复项目管理员
- **那么** 系统拒绝该修改

### Requirement: 超级管理员可以恢复项目管理员
超级管理员即使尚未加入项目，也 MUST 能够将活动用户指定为项目管理员；该操作必须保证项目至少保留一个管理员。

#### Scenario: 为无管理员项目指定管理员
- **当** 超级管理员将活动用户指定为无管理员项目的 `project_admin`
- **那么** 该用户成为显式项目成员，且恢复操作被审计

#### Scenario: 恢复目标用户已停用
- **当** 超级管理员选择停用用户作为项目管理员
- **那么** 系统拒绝恢复操作且不改变成员关系

### Requirement: 超级管理员接管项目必须显式执行
超级管理员接管项目时 MUST 提交非空原因；成功接管必须先新增或提升显式 `project_admin` 成员关系，之后才能访问项目内容。

#### Scenario: 超级管理员接管项目
- **当** 超级管理员提交有效接管原因
- **那么** 系统授予其显式 `project_admin` 成员关系，并在语义化审计事件中记录原因

#### Scenario: 未填写接管原因
- **当** 超级管理员未提交非空原因就尝试接管项目
- **那么** 系统拒绝请求且不改变成员关系

### Requirement: 项目管理员无需全局目录权限即可发现成员候选人
系统 MUST 提供分页的项目范围成员候选人查询，只返回添加成员所需的最小活动用户身份信息。

#### Scenario: 项目管理员搜索成员候选人
- **当** 项目管理员搜索可加入项目的活动用户
- **那么** 系统返回匹配的用户标识和用户名，但不授予全局用户管理权限

#### Scenario: 项目编辑者搜索成员候选人
- **当** 不具备成员写权限的项目编辑者调用候选人接口
- **那么** 系统拒绝请求

### Requirement: 授权只加载当前项目范围
项目认证请求 MUST 只加载当前项目的授权，登录和个人资料响应不得返回用户完整的项目角色映射。

#### Scenario: 用户加入大量项目但只访问一个项目
- **当** 用户请求一个项目范围路由
- **那么** 后端只评估该项目的当前成员关系

#### Scenario: 前端切换当前项目
- **当** 用户选择另一个可见项目
- **那么** 前端调用 `/api/projects/{project_id}/access`，并根据返回的当前项目权限更新可执行操作

### Requirement: 保护最后一个项目管理员
除非有权限的恢复操作在同一事务中建立另一个管理员，否则系统 MUST 拒绝移除或降级最后一个活动项目管理员。

#### Scenario: 移除唯一项目管理员
- **当** 通过普通成员管理移除或降级项目唯一管理员
- **那么** 系统拒绝该修改
