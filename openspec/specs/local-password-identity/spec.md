# local-password-identity Specification

## Purpose

定义单租户平台本地密码账户、登录防护、会话轮换与撤销以及 JWT 校验的安全行为。确保管理员设置的密码可直接使用，用户可自愿改密，同时保留账号锁定、会话失效和令牌重放防护。

## Requirements

### Requirement: 管理员设置的凭据可直接使用
系统 MUST 允许活动用户使用管理员创建或重置的密码完成正常登录并访问其已有权限允许的平台和项目功能，不得要求首次登录时修改密码。系统 MUST 同时允许用户在安全设置中主动修改密码。

#### Scenario: 新用户使用管理员设置的密码登录
- **当** 活动用户使用管理员创建的密码通过认证
- **那么** 系统签发正常会话，并允许用户访问其已有权限允许的普通平台和项目功能

#### Scenario: 历史强制改密标记不限制访问
- **当** 活动用户的既有数据仍为 `must_change_password=true` 且其密码认证成功
- **那么** 系统签发正常会话，且不得因该标记限制登录、刷新、普通 API 或前端路由

#### Scenario: 用户主动修改密码
- **当** 用户在安全设置中提交有效的当前密码和符合要求的新密码
- **那么** 系统更新密码、撤销既有刷新会话并签发替代会话

### Requirement: 限制本地登录失败次数
系统 MUST 累计既有账号的连续错误密码次数，在连续五次失败后锁定账号十五分钟，并且公开登录错误不得暴露用户名是否存在或账号是否已锁定。

#### Scenario: 第五次连续密码错误
- **当** 一个账号发生第五次连续错误密码尝试
- **那么** 系统记录十五分钟后的解锁时间，并返回统一的用户名或密码错误响应

#### Scenario: 锁定期间登录
- **当** 用户在锁定到期前提交正确凭据
- **那么** 系统拒绝登录且不签发令牌

#### Scenario: 锁定到期后成功登录
- **当** 锁定到期后提交正确凭据
- **那么** 系统完成认证并清空失败次数和锁定时间

### Requirement: 重置凭据必须撤销现有会话
系统 MUST 只允许具备平台凭据重置权限的管理员重置他人密码。重置后的密码可直接用于正常登录，并且系统必须撤销该用户的全部刷新令牌 family。

#### Scenario: 超级管理员重置普通用户密码
- **当** 有权限的超级管理员为活动或停用的非超级管理员设置有效密码
- **那么** 系统只保存密码哈希、不要求首次改密、撤销既有刷新会话并记录凭据重置审计事件

#### Scenario: 无权限重置凭据
- **当** 不具备凭据重置权限的主体尝试重置密码
- **那么** 系统拒绝请求，且不改变密码或会话

### Requirement: 刷新令牌只能轮换一次
系统 MUST 原子消费刷新令牌，在消费成功后于同一会话 family 中签发替代令牌，并在已经消费的令牌被重放时撤销整个 family。

#### Scenario: 并发请求使用同一刷新令牌
- **当** 两个并发请求提交同一个有效刷新令牌
- **那么** 只能有一个请求成功，另一个必须以令牌重放被拒绝

#### Scenario: 重放已消费刷新令牌
- **当** 再次提交已经消费的刷新令牌
- **那么** 系统撤销该令牌 family 并拒绝请求

### Requirement: JWT 必须绑定当前平台
系统在接受 access token 或 refresh token 前，MUST 校验签名、允许算法、签发方、受众、令牌类型、过期时间、生效时间、主体、JWT ID 和配置的签名密钥标识。

#### Scenario: 令牌受众错误
- **当** 一个签名正确的令牌使用了非当前平台的受众
- **那么** 系统拒绝该令牌

#### Scenario: 令牌使用未知密钥标识
- **当** 令牌头中的 `kid` 不存在于配置的验证密钥集合
- **那么** 系统拒绝该令牌

#### Scenario: 密钥轮换期间旧验证密钥仍有效
- **当** 未过期令牌由仍在配置中的旧验证密钥签发
- **那么** 若其余声明全部有效，系统接受该令牌，同时新令牌使用当前活动签名密钥

### Requirement: 停用用户不得保留访问权
系统 MUST 拒绝停用用户登录、使用 access token 认证或使用 refresh token 刷新会话。

#### Scenario: 管理员停用已登录用户
- **当** 有权限的管理员停用用户
- **那么** 系统撤销该用户的刷新会话，并在后续认证请求加载当前用户状态时拒绝访问
