# v0.4.0 发版执行清单

## 发布口径

- 版本号：`v0.4.0`
- 发版对象：整个仓库
- 发版基线：`main`
- 版本口径：可信运行时与聊天 v2 工作台

## 发版前检查

- `main` 包含 `optimize-chat-interaction-runtime` 已验收、同步并归档的规格
- `docs/CHANGELOG.md` 和 `v0.4.0-agent-workspace-demo-draft.md` 已就绪
- 工作树干净，关键服务与前端校验通过

## 最终校验

```bash
openspec validate --all --strict --no-interactive
(cd apps/platform-api && uv run python -m unittest discover -s tests -p 'test*.py' -v)
pnpm --dir apps/platform-web lint
pnpm --dir apps/platform-web typecheck
pnpm --dir apps/platform-web build
```

## 发布

```bash
git tag -a v0.4.0 -m "release: v0.4.0"
git push origin main v0.4.0
```

推送 tag 后，`.github/workflows/release.yml` 将使用
`v0.4.0-agent-workspace-demo-draft.md` 自动创建正式 GitHub Release。
