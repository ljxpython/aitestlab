# v0.3.1 发版执行清单

## 1. 发布口径

- 版本号：`v0.3.1`
- 发版对象：整个仓库
- 发版基线：`main`
- 版本口径：Harness 与本地知识栈闭环版

## 2. 发版前检查

- 功能分支已合并到 `main`
- `adopt-openspec-harness` 已接受、同步 capability spec 并归档
- `docs/CHANGELOG.md` 已形成 `v0.3.1` 条目
- Release 文案已覆盖 `v0.3.0..main` 的完整变更
- 工作树干净，关键验证通过

## 3. 最终校验

```bash
python3 scripts/check_docs.py
openspec validate --all --strict --no-interactive
uv run --project apps/platform-api python -m unittest discover -s tests -p 'test*.py' -v
pnpm --dir apps/platform-web lint
pnpm --dir apps/platform-web typecheck
pnpm --dir apps/platform-web build
```

## 4. 提交发布记录

```bash
git add docs/CHANGELOG.md docs/releases README.md openspec
git commit -m "docs(release): prepare v0.3.1"
git push origin main
```

## 5. 创建并推送 tag

```bash
git tag -a v0.3.1 -m "release: v0.3.1"
git push origin v0.3.1
```

## 6. 创建 GitHub Release

```bash
gh release create v0.3.1 \
  --title "v0.3.1 - Harness 与本地知识栈闭环版" \
  --notes-file "docs/releases/v0.3.1-agent-workspace-demo-draft.md"
```

## 7. 发版后确认

- `origin/main`、本地 `main` 和 `v0.3.1` 指向同一 release commit
- GitHub Release 已发布且不是 draft/prerelease
- `docs/CHANGELOG.md` 的 Unreleased 已切换到 `v0.3.2`
- OpenSpec active changes 列表不再包含 `adopt-openspec-harness`
