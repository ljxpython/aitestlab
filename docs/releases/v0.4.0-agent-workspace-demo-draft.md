# v0.4.0 - 可信运行时与聊天 v2 工作台

> 正式发布说明，可直接用于 GitHub Release。

## Summary

`v0.4.0` 将平台聊天主线迁移到受管的 v2 运行时契约：服务端生成可信身份和项目上下文，前端以流式 SDK 状态作为唯一运行真相，同时提供独立调试工作台。

## Highlights

- 正式聊天使用 v2 流式运行时，覆盖续接、中断、工具调用和历史消息展示
- 模型、工具和 prompt 配置通过受管运行时契约进入每次运行
- 身份与项目上下文由服务端生成，不再依赖前端注入可信字段
- 调试能力独立为工作台，避免污染正式聊天交互

## Added

- 聊天 v2 状态适配、运行元数据展示和独立 Debug 工作台
- 运行时委派、平台认证和运行上下文解析的服务端实现与回归测试
- 运行级模型、工具和 prompt 配置入口

## Changed

- 正式聊天收敛到 LangChain 流式 SDK 的运行状态
- 前端聊天依赖升级并收敛消息、工具调用和中断交互
- 运行时请求使用可信服务端上下文，部署配置同步更新

## Fixed

- 修复 `runtime_delegation_not_configured` 导致聊天无法运行的问题
- 修复发送消息后的页面闪烁、线程目标恢复和线程搜索兼容性问题

## Verification

- `openspec validate --all --strict --no-interactive`
- `uv run python -m unittest discover -s tests -p 'test*.py' -v`（在 `apps/platform-api` 目录执行）
- `pnpm --dir apps/platform-web lint`
- `pnpm --dir apps/platform-web typecheck`
- `pnpm --dir apps/platform-web build`
- 前端 E2E：发送消息、流式响应、工具调用、中断和历史续接

## Known Issues
